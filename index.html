# Vocab Trainer (HTML5) Teen-friendly vocabulary trainer. **10 units × 5 lessons = 50 slots**. Works offline in the browser (Safari / Chrome). Progress is saved in `localStorage` per lesson. ## Structure ``` vocab-trainer/ ├── index.html # Hub: all units & lessons ├── README.md └── units/ ├── unit-01/ │ ├── lesson-01.html # Ready: Повседневные занятия │ ├── lesson-02.html # Ready: Daily routines │ ├── lesson-03.html # Ready: Everyday phrases │ ├── lesson-04.html # Placeholder │ └── lesson-05.html # Placeholder ├── unit-02/ … unit-10/ # 5 placeholders each ``` ## Features (ready lessons) - Flashcards, matching, quiz, gaps, word order, spelling, sentences, pronunciation - **Story mode** — write a mini-story with 3 words - **YouGlish** — hear native speakers - Custom photos per word - XP, levels, badges, combos, daily goal - User-paced feedback (“Далее →”) ## Upload to GitHub ### 1. Create a repo on GitHub - Go to https://github.com/new - Name e.g. `vocab-trainer` - Public (needed for free GitHub Pages) - **Do not** add README if you already have this folder ### 2. From this folder (terminal) ```bash cd vocab-trainer git init git add . git commit -m "Initial commit: 10 units x 5 lessons" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/vocab-trainer.git git push -u origin main ``` ### 3. Enable GitHub Pages - Repo → **Settings** → **Pages** - Source: **Deploy from a branch** - Branch: `main` / folder `/ (root)` - Save Site URL will be: `https://YOUR_USERNAME.github.io/vocab-trainer/` ### 4. Add a new lesson later 1. Copy a ready file, e.g. `units/unit-01/lesson-01.html` 2. Replace the `WORDS=[...]` list and titles 3. Save as `units/unit-XX/lesson-YY.html` 4. Update the title in `index.html` if needed 5. Commit and push: ```bash git add . git commit -m "Add Unit X Lesson Y" git push ``` ## Local preview Open `index.html` in a browser, or: ```bash npx --yes serve . ``` ## Note on storage Each lesson uses its own `localStorage` key (`vocab_1A_v2`, etc.). Photos are stored as compressed JPEG data URLs — keep them small.
